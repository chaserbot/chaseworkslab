## What It Is in This Setup
Full *arr media management stack running on Mac Mini #1 (macOS, `10.27.27.22`) via Docker Compose. Handles automated downloading, organization, and management of TV, movies, and music. Media is stored on the Pegasus DAS (Thunderbolt-attached to Mac Mini #1).

## Services in the Stack

| Service | Role | Notes |
|---|---|---|
| Sonarr | TV show management | Monitors, grabs, renames TV |
| Radarr | Movie management | Monitors, grabs, renames movies |
| Prowlarr | Indexer management | Central indexer proxy for Sonarr/Radarr |
| qBittorrent | Download client | Torrent backend |
| Overseerr | Request management | User-facing request UI, integrates Sonarr/Radarr |
| Audiobookshelf | Audiobook / podcast server | Separate from arr, but same host |

## Current State
- All services running on Mac Mini #1 (macOS)
- Managed via Docker Compose
- Media stored on Pegasus DAS (mounted locally on Mac Mini #1)
- Working and active

## Host
- **Machine**: Mac Mini #1 (A1347, macOS)
- **IP**: `10.27.27.22`
- **Storage**: Pegasus DAS via Thunderbolt

## Key Config Details
- All services run in Docker containers via Docker Compose
- Config directories live on Mac Mini #1's local filesystem (NOT on the Pegasus DAS)
- Media paths mount from the Pegasus DAS into containers
- `*/config/` directories contain API keys, auth tokens — **never commit these**
- Only `docker-compose.yml` and `.env` structure belong in git; config dirs are gitignored
