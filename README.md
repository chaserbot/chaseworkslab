# homelab-context

Private repo. Context files for Claude Code sessions.

## How to use

Start any Claude Code session with:
```
Read [filename].md in my homelab-context repo and let's pick up where I left off.
```

## Files

| File | Repo it supports | Status |
|------|-----------------|--------|

## Rule

Update the "Last session" block in the relevant file before ending every session.
That's the whole system.
